Put the OFFICIAL WinDjView 2.1 binaries here to build the full installer (they are not stored in git):

  installer/bin/x64/WinDjView.exe   64-bit (required)
  installer/bin/x86/WinDjView.exe   32-bit (optional: enables 32-bit Windows support in the installer)

The installer was tested with the official 64-bit WinDjView.exe 2.1 (4,460,544 bytes, built 2015-02-23),
SHA-256 d1049efef77554446171ba94c69cee78bb6b0b9fdade3e1b5dc93468da6ce0c0
Get it from https://sourceforge.net/projects/windjview/files/ (or copy WinDjView.exe from an installed copy).
The exe is used unmodified. Its source is in this repository (../windjview, GPL v2 or later).
