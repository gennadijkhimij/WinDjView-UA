# DjVuLibre: перенесені виправлення безпеки

`windjview/libdjvu` — це DjVuLibre **3.5.25.3** (2012) з власними змінями WinDjView
(104 позначки `Changed for WinDjView project` у 34 файлах). Повна заміна бібліотеки зламала б ці зміни,
тому в WinDjView-UA 2.1.2 перенесено **виправлення безпеки** з офіційної DjVuLibre
(https://sourceforge.net/p/djvu/djvulibre-git/, до версії 3.5.30.1, червень 2026).

Спосіб: гілка від офіційної `3.5.25.3` → коміт бібліотеки WinDjView → `git apply --3way` кожного
виправлення (лише файли, які є в бібліотеці WinDjView; `ddjvuapi`/`miniexp` не використовуються).
Один конфлікт (`GString.cpp`) розв'язано на користь безпечного варіанта (`snprintf` з межею буфера).

Відповідність номерів CVE комітам наведено за описами DjVuLibre, Debian і Fedora; окремо кожну CVE
на експлойті не перевіряли. Перевірено: збирання x64/x86, відкриття й відображення документів,
40 випадково пошкоджених файлів — без падінь.

Поведінка, змінена офіційним виправленням `7993b44`: якщо в потоці декодування лишається
неперехоплена помилка, програма завершується (`abort`), а не продовжує роботу з пошкодженим станом.
