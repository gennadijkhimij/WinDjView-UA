## Що нового — кіберзахист

- **Виправлення безпеки бібліотеки DjVuLibre 2014–2026**, зокрема CVE-2019-15142…15145, CVE-2019-18804, CVE-2021-3500, CVE-2021-3630, CVE-2021-32490…32493, CVE-2025-53367 ([перелік](https://github.com/gennadijkhimij/WinDjView-UA/blob/main/docs/DJVULIBRE-BACKPORTS.md)).
- **Захист від підміни DLL:** мовна бібліотека завантажується лише як ресурси (її код не виконується), системні бібліотеки — лише з System32.
- Перевірка оновлень перенесена на GitHub (з версії 2.1.1 вона зверталася до SourceForge).
- У властивостях файлів — назва продукту WinDjView-UA.

## Завантаження

`WinDjView-UA-2.1.2-Setup.exe` (64- і 32-бітна Windows), контрольна сума — у `SHA256SUMS.txt`.

*English:* DjVuLibre security fixes 2014–2026 backported, resource-only language DLL and safe DLL search paths, update check moved to GitHub. A newer version is available.
