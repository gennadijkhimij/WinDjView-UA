## Що нового

- У 64-бітній установці мовна бібліотека `WinDjViewUA.dll` тепер теж 64-бітна (раніше через налаштування проєкту вона збиралася 32-бітною; програма працювала, але файли не збігалися за розрядністю).

## Завантаження

`WinDjView-UA-2.1.4-Setup-x64-x86.exe` — один інсталятор для 64- і 32-бітної Windows. Контрольна сума — у `SHA256SUMS.txt` ([інструкція](https://github.com/gennadijkhimij/WinDjView-UA/blob/main/docs/INSTALL.md)).

*English:* the 64-bit installation now ships a 64-bit `WinDjViewUA.dll`. A newer version is available.
