## Що нового

- **Інсталятор сам закриває запущену WinDjView-UA** перед оновленням (спершу питає; у тихому режимі `/S` закриває автоматично). Раніше запущена програма спричиняла помилку «Помилка під час відкриття файлу для запису». Те саме — у деінсталятора. Офіційний WinDjView (інша тека) не зачіпається.
- **Виправлено нечитабельні українські написи** у вікнах інсталятора.

## Завантаження

**`WinDjView-UA-2.1.5-Setup-x64-x86.exe`** — один інсталятор для 64- і 32-бітної Windows (потрібну версію вибирає сам). Ставиться в `C:\Program Files\WinDjView-UA` поверх попередньої версії, налаштування зберігаються. Тихе встановлення: `/S`.

Перевірте контрольну суму з `SHA256SUMS.txt` — [інструкція](https://github.com/gennadijkhimij/WinDjView-UA/blob/main/docs/INSTALL.md). Інсталятор поки без цифрового підпису, тому Windows може показати попередження «невідомий видавець».
