## Завантаження

**`WinDjView-UA-{VERSION}-Setup-x64-x86.exe`** — один інсталятор для 64- і 32-бітної Windows. Перевірте SHA-256 з `SHA256SUMS.txt` — [інструкція](https://github.com/gennadijkhimij/WinDjView-UA/blob/main/docs/INSTALL.md). Інсталятор поки без цифрового підпису, тому Windows може показати попередження «невідомий видавець».
