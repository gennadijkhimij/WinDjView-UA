# Встановлення WinDjView-UA

## 1. Завантаження — лише з офіційної сторінки

https://github.com/gennadijkhimij/WinDjView-UA/releases/latest

Унизу опису релізу, у блоці **Assets**:

| Файл | Що це |
|---|---|
| **`WinDjView-UA-<версія>-Setup.exe`** | інсталятор — завантажувати його |
| `SHA256SUMS.txt` | контрольна сума для перевірки |
| `Source code (zip / tar.gz)` | вихідний код (звичайному користувачу не потрібен) |

Не завантажуйте WinDjView-UA з інших сайтів і файлообмінників.

## 2. Перевірка файлу (рекомендовано)

Контрольна сума підтверджує, що файл завантажився цілим і його не підмінили.
У PowerShell, у теці із завантаженим файлом:

```powershell
Get-FileHash .\WinDjView-UA-2.1.2-Setup.exe -Algorithm SHA256
```

Результат має **повністю** збігатися з рядком у `SHA256SUMS.txt` того самого релізу.
Якщо не збігається — не запускайте файл, завантажте заново.

## 3. Запуск інсталятора

Інсталятор поки без цифрового підпису (див. [політику підпису](CODE_SIGNING_POLICY.md)), тому:

- браузер може написати «зазвичай не завантажується» → **⋯ → Зберегти → Усе одно зберегти**;
- Windows SmartScreen: «Windows захистила ваш комп'ютер» → **Докладніше → Усе одно запустити**
  (лише якщо контрольна сума збіглася);
- запит прав адміністратора → **Так**.

Далі: мова, ліцензія, компоненти (ярлик на робочому столі — за бажанням), **Встановити**.
Тека за замовчуванням — `C:\Program Files\WinDjView-UA`; не змінюйте її на теку, куди можуть
писати всі користувачі (наприклад, `C:\WinDjView`).

Програма запускається українською; англійська — «Вигляд → Мова (Language)».

## 4. Оновлення

Програма раз на тиждень перевіряє, чи є нова версія, і пропонує відкрити сторінку релізів.
Нову версію встановлюйте поверх старої — налаштування зберігаються.

## Для адміністраторів (кілька комп'ютерів)

```
WinDjView-UA-2.1.2-Setup.exe /S                 (тихе встановлення / оновлення)
"C:\Program Files\WinDjView-UA\uninstall.exe" /S (тихе видалення)
```

Вимкнути щотижневу перевірку оновлень для користувача: параметр `check-updates` = 0 (DWORD)
у `HKCU\Software\WinDjView-UA\WinDjView\Settings` або через «Налаштування → Додатково».

Детальніше про кіберзахист — [SECURITY.md](SECURITY.md).
